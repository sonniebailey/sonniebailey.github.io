{# Built-in icon set for feature cards. A feature's `icon` in the page frontmatter names one of these, for example `icon: calendar`. Keeping them as named SVGs rather than emoji means they inherit the brand colour and render identically on every platform; emoji are drawn by the operating system and look different (and usually out of place) on each one. To add an icon: add a {% raw %}{% elif %}{% endraw %} branch below with a 24x24 stroked path. Anything unrecognised falls through to a neutral dot, so a typo in a page's frontmatter degrades quietly rather than failing a build. #} {% macro feature_icon(name) -%} {%- endmacro %}
